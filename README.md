# Backend-.NET-aplicando-Clean-Arquitecture-
Backend en .NET con Clean Architecture y Entity Framework que gestiona la entidad Persona. Incluye operaciones de creación, actualización, búsqueda y eliminación, asegurando separación de capas, persistencia eficiente y una API REST para interacción con clientes.
